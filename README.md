Автоматизированный ML-пайплайн прогнозирования оттока клиентов телеком-оператора
Описание проекта

Цель проекта — разработка автоматизированного ML-пайплайна для прогнозирования оттока клиентов (Customer Churn Prediction) в телекоммуникационной отрасли.

Для реализации использован открытый датасет IBM Telco Customer Churn, содержащий информацию о клиентах оператора связи: длительность обслуживания, тип контракта, подключённые услуги, способ оплаты и ежемесячные платежи.

Поскольку реальные данные российских телеком-операторов не находятся в открытом доступе, данный набор данных используется в качестве отраслевого аналога (proxy dataset). Архитектура решения не зависит от конкретного оператора и может быть адаптирована для использования на данных ПАО «Ростелеком» или другой телекоммуникационной компании.

Разработанный пайплайн выполняет:

загрузку и подготовку данных;
обучение модели машинного обучения;
оценку качества прогнозирования;
сохранение модели;
мониторинг метрик качества;
автоматизированное тестирование;
контейнеризацию с использованием Docker;
автоматический запуск проверок через CI/CD.

Проект демонстрирует полный жизненный цикл ML-системы (MLOps) от подготовки данных до развёртывания и мониторинга модели.
