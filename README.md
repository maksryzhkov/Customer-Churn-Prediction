# Автоматизированный ML-пайплайн прогнозирования оттока клиентов телеком-оператора

## Описание проекта

Цель проекта — разработка системы прогнозирования оттока клиентов телекоммуникационной компании с использованием методов машинного обучения.

В качестве данных используется открытый датасет IBM Telco Customer Churn, содержащий информацию о клиентах оператора связи.

## Структура пайплайна

1. Загрузка данных.
2. Очистка и подготовка данных.
3. Кодирование категориальных признаков.
4. Масштабирование числовых признаков.
5. Обучение модели.
6. Оценка качества.
7. Сохранение модели.
8. Мониторинг метрик.

## Используемые технологии

* Python
* Pandas
* Scikit-learn
* MLflow
* Docker
* GitHub Actions
* Pytest

## Запуск проекта

Установка зависимостей:

pip install -r requirements.txt

Запуск:

python pipeline.py

## Запуск через Docker

docker build -t churn-pipeline .

docker run --rm churn-pipeline

## Результаты

После запуска автоматически рассчитываются:

* Accuracy
* Precision
* Recall
* F1-score
* ROC-AUC

## Тестирование

pytest tests/

## CI/CD

GitHub Actions автоматически запускает тестирование и сборку Docker-образа при каждом push в ветку main.

## Ограничения проекта

Используется открытый учебный датасет. Для внедрения в конкретной компании требуется переобучение модели на внутренних данных организации.
